# ClubStat — учёт посещений клуба

## Запуск
Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

Из корня репозитория выполните:

```bash
python -m src.ClubStat.main
```

База данных SQLite создаётся автоматически в `src/ClubStat/clubstat.db`.

## Возможности
- Регистрация клиента и вход с безопасным хешированием паролей (PBKDF2).
- Роли клиента и администратора.
- Просмотр занятий и тренеров.
- Управление занятиями и тренерами для администратора.
- Бронирование и отмена собственных записей клиентом.
- Просмотр всех бронирований и их отмена администратором.

## Учётная запись администратора
При первом запуске создаётся только справочник ролей. Первый администратор должен быть создан вручную через SQLite, либо назначен существующему пользователю изменением `user_role` на `1`. Регистрация через меню всегда создаёт клиента.

## Структура
- `models` — dataclass-модели таблиц.
- `repositories` — SQL и CRUD-доступ к данным.
- `services` — проверки и бизнес-логика.
- `database` — подключение и инициализация SQLite.
- `main.py` — консольный интерфейс.
