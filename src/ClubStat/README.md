# ClubStat — учёт посещений клуба

## Требования
Python 3.10 или новее. Сторонние библиотеки не требуются.

## Первый запуск
Из корневой папки репозитория выполните:

```bash
python -m src.ClubStat.admin_setup
python -m src.ClubStat.main
```

Первая команда интерактивно создаёт администратора (пароль вводится скрыто). Регистрация в приложении создаёт только клиентские учётные записи. База SQLite автоматически создаётся в `src/ClubStat/clubstat.db`.

## Возможности
- Регистрация клиента и авторизация.
- Хеширование паролей PBKDF2-HMAC-SHA256 с индивидуальной случайной солью.
- Роли администратора и клиента.
- Просмотр занятий и тренеров.
- Добавление и удаление занятий.
- Добавление тренеров и назначение тренеров занятиям.
- Просмотр всех бронирований администратором.
- Бронирование, просмотр и отмена собственных записей клиентом.
- Отмена любых бронирований администратором.

## Архитектура
- `models` — модели таблиц на базе `dataclass`.
- `repositories` — SQL-запросы и CRUD-доступ к данным.
- `services` — проверки и бизнес-логика.
- `database` — подключение и инициализация SQLite.
- `main.py` — консольный интерфейс с разделением прав.
- `admin_setup.py` — первоначальное создание администратора.

## Важно при обновлении старой версии
Новая схема использует столбец `password_hash` вместо старого `password`. Если у вас уже есть старая база `src/ClubStat/clubstat.db`, сначала сделайте резервную копию, затем удалите старый файл БД и запустите приложение заново. Инициализация не удаляет существующие таблицы и записи.
